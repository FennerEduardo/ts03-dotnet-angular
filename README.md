# ts03-dotnet-angular

Reference project for [gherkin-ai](https://github.com/FennerEduardo/gherkin-ai-cli) 3.0.0. Saga execution in ASP.NET Core 8 with EF Core, and an Angular 22 frontend.

Everything in `generated-specs/` was generated by `ghk generate` from the specification in `features/dotnet_saga_execution.feature`. The project builds, and its generated tests and runtime integration suite pass, as verified on 2026-10-06 (see [Verification](#verification)).

## Stack

| Part | Technology |
|---|---|
| Backend | ASP.NET Core 8 (C#, EF Core) |
| Frontend | Angular 22 (NgRx Signals, zoneless) |
| Runtime kernel | PostgreSQL command service with idempotency and transactional outbox, RabbitMQ relay and inbox consumer with dead-letter queue, saga orchestrator, OpenTelemetry trace propagation |
| Architecture (configuration) | `monolith` |

> The configuration names `mysql` as the database, which shapes the generated schema. The runtime kernel and its integration suite use PostgreSQL, the database gherkin-ai 3.0 verifies the runtime against.

## Build and test

The commands below are the ones gherkin-ai uses to verify this stack. Run them in `generated-specs` with the toolchain installed, or inside the official image `mcr.microsoft.com/dotnet/sdk:8.0`.

```bash
cd generated-specs
dotnet build tests/*/*.Tests.csproj -nologo -v q
dotnet test tests/*/*.Tests.csproj -nologo -v q --no-build --filter "Category!=Integration&Category!=Testcontainers"
```

Runtime integration suite (IT1–IT7: transactional outbox, idempotency under concurrency, exactly-once relay, tenant isolation, saga compensation, inbox deduplication and dead-lettering, trace propagation):

```bash
docker run -d --name ghk-pg -e POSTGRES_PASSWORD=ghk -p 5432:5432 postgres:17-alpine
docker run -d --name ghk-mq -e RABBITMQ_DEFAULT_USER=ghk -e RABBITMQ_DEFAULT_PASS=ghk -p 5672:5672 rabbitmq:4-alpine
export DATABASE_URL=postgres://postgres:ghk@localhost:5432/postgres AMQP_URL=amqp://ghk:ghk@localhost:5672
dotnet test tests/*/*.Tests.csproj -nologo --no-build --filter "Category=Integration" --logger "console;verbosity=normal"
```

Frontend (`generated-specs/frontend`, image `node:24-bookworm`):

```bash
cd generated-specs/frontend
npm install --no-audit --no-fund --loglevel=error
npm run build
npm test
```
